Use the current official Blackmagic Design documentation for version-specific features.

Official color resources:

https://www.blackmagicdesign.com/products/davinciresolve/color

## General workflow

1. Import and organize media.
2. Confirm color-management settings.
3. Normalize or transform source footage.
4. Correct exposure and white balance.
5. Match shots.
6. Build the creative look.
7. Review scopes and image quality.
8. Deliver in the required color space.

Exact controls and menu locations can change between Resolve versions, so the skill should link to current official documentation rather than hard-code unstable UI instructions.
