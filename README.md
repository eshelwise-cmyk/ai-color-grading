# AI Color Grading

A standalone skill library for taking camera footage from storage through color-managed preparation, correction, shot matching, creative grading, and delivery.

## Core workflow

SSD → ingest → organize → identify camera/color space → color management → technical correction → shot matching → creative grade → QC → export

## Focus

- Color science
- Camera and log workflows
- RAW processing
- Color management
- Exposure and white balance
- Contrast and tonal shaping
- Skin tones
- Shot matching
- Look development
- LUTs and transforms
- DaVinci Resolve workflows

## Rule

Technical normalization and creative grading are separate steps. Preserve source media and make changes reversible where the software allows it.
